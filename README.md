## Project 2: Basic HTML Website

Project URL:
https://anuhya3.github.io/roadmap.sh/basic-html-website/

Project Page:
https://roadmap.sh/projects/basic-html-website

### Technologies Used
- HTML5
- Semantic HTML
- SEO Meta Tags
- HTML Forms
- Navigation Links

### Description
A simple multi-page website built using semantic HTML.
The project includes a homepage, projects page, articles page,
and contact page with a form for name, email, and message.
It features navigation links across all pages, SEO meta tags,
and a structured layout ready for future CSS styling.
